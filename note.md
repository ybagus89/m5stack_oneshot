Dari daftar pin yang Anda berikan (1, 2, 3, 5, 16, 17, 18, 19, 21, 22, 23, 25, 26, 35, 36), berikut adalah pin yang dapat digunakan untuk PWM pada M5Stack Core (berbasis ESP32):

GPIO 2 - Dapat digunakan untuk PWM.
GPIO 5 - Dapat digunakan untuk PWM.
GPIO 16 - Dapat digunakan untuk PWM.
GPIO 17 - Dapat digunakan untuk PWM.
GPIO 18 - Dapat digunakan untuk PWM.
GPIO 19 - Dapat digunakan untuk PWM.
GPIO 21 - Dapat digunakan untuk PWM.
GPIO 22 - Dapat digunakan untuk PWM.
GPIO 23 - Dapat digunakan untuk PWM.
GPIO 25 - Dapat digunakan untuk PWM.
GPIO 26 - Dapat digunakan untuk PWM.
Pin GPIO 35 dan 36 adalah pin input-only dan tidak dapat digunakan untuk PWM.

Jadi, dari pin yang Anda sebutkan, Anda dapat menggunakan pin 2, 5, 16, 17, 18, 19, 21, 22, 23, 25, dan 26 untuk PWM. Pastikan untuk memeriksa dokumentasi dan spesifikasi M5Stack Core untuk memastikan bahwa pin yang Anda pilih tidak digunakan untuk fungsi lain yang mungkin mengganggu aplikasi Anda.
